# Student Management System

A web-based Student Management System developed using
HTML, CSS, JavaScript, PHP and JSON.

## Features

- Add student details
- View student records
- Update student information
- Delete student records
- Search students
- JSON data storage

## Technologies

- HTML
- CSS
- JavaScript
- PHP
- JSON

## How to Run

1. Install PHP.
2. Open the project folder in CMD.
3. Run:

   php -S localhost:8000

4. Open your browser.
5. Visit http://localhost:8000
